# Change: stt-runs

## Driver
"Analyse = runs. One run = speech model, then (optionally) an AI model... Every run is kept and labelled with model + time." (DESIGN.md §1). The user's main question is which speech model is best on his Greek, so a run must be repeatable, labelled and comparable. Measured baseline (BRIEF): large-v3 18.8% wrong, turbo 26.7%.

## Depends on
v2-foundation (package, config, migration runner) → recording-capture (`recording` table, audio files, audio endpoint) → library-page → **jobs-and-models**.
Exact interface from `jobs-and-models` / foundation (SPEC-RULES "Integration contract"; used as written):
- `steps = StepRegistry()`; step registered with `@steps.register("stt_transcribe")` in `src/details/runner/steps_stt.py`, imported in `create_app`.
- `JobService.enqueue(kind, recording_id, steps=[str|{"name","params"}], params={}) -> job_id` (HTTP `POST /api/jobs`); SSE and polling per jobs-and-models.
- `StepContext`: `job_id, step_name, params, cancelled, step_dir, data_dir, settings, memory, progress(pct,msg), spawn_child(argv)`. `step_dir` (`<data_dir>/jobs/<job_id>/<step>/`) is the only checkpoint dir.
- `await ctx.memory.release_for_stt()` before spawning; child processes print one stdout line at model load and at least one per window (heartbeat).
- `@steps.on_terminal("stt_transcribe")` finalizer runs when a job ends cancelled or failed, including while still queued.
- `GET /api/models?kind=stt` entries: `{id, kind, label, engine, role, needs_gb, installed, unavailable_reason?, hint?}`; unknown model id on POST = 422. `models.toml` ships `whisper-turbo` and `whisper-large` (engine `mlx_whisper`); this change adds NO entries.
- Audio from `GET /api/recordings/{id}/audio` (recording-capture); `v1-transcript.txt` written by the importer (recording-capture).
- Pages: `web/analyse/index.html` served at `/analyse`; links `/analyse?rec=<id>`, `/library`.

## Decision
1. **Migration 0004:** `stt_run(id uuid, recording_id → recording ON DELETE CASCADE, job_id → job ON DELETE SET NULL (lets the page re-attach progress after a reload), engine, model_id, model_revision, settings jsonb, language, status, started_at, finished_at, wall_ms, audio_ms, rtf, error, text, raw jsonb, created_at)` and `transcript_segment(id, stt_run_id → stt_run ON DELETE CASCADE, idx, start_ms, end_ms, text, avg_logprob, no_speech_prob, words jsonb, unique(stt_run_id, idx))`. Integer milliseconds only. Rows are append-only; a re-run is a new row. `rtf` = audio seconds / wall seconds (">1 = faster than real time", shown as "18×").
2. **Engine registry shape:** `engines/__init__.py` holds `ENGINES: dict[str, type[SttEngine]]`. `SttEngine` protocol (engine id `mlx_whisper`): `transcribe_window(audio_path, start_s, end_s, settings) -> list[Segment{start_ms,end_ms,text,words?,avg_logprob?,no_speech_prob?}]`, plus class attrs `name`, `supports_words`. A `models.toml` `[stt.<id>]` block carries `engine` and engine-specific keys (`repo` for `mlx_whisper`; a future `path` for onnx-asr). v2.0 registers only `mlx_whisper` and uses the jobs-and-models entries `whisper-turbo` and `whisper-large`. Parakeet-Greek and OpenCouncil adapters are v2.1: adding one = one new class in `engines/` + one registry line + one `models.toml` block, with no change to runner, API or page.
3. **mlx-whisper adapter runs as a child process:** `python -m details.engines.worker` receives a JSON job spec, loads the model once, transcribes the audio in windows (`[stt] window_s`, default 30), and appends one JSON line per finished window to `segments.jsonl` in `ctx.step_dir` (flush + fsync), then writes `worker.done.json` (not `done.json`: the runner owns that name as the step marker, and a worker-written one would make a retry skip the step). On resume the worker skips windows already in the file. The worker prints one stdout line at model load and one per window (the runner's heartbeat); the step spawns it with `ctx.spawn_child(argv)` after `await ctx.memory.release_for_stt()` and calls `ctx.progress` from the window count. Settings passed through: `language` (`el` | `auto`), `initial_prompt` (vocab hint, from `[stt] vocab_hint` in `config.toml`, overridable per run), `condition_on_previous_text=False` (fixed, not a form option).
4. **Greek postfix:** after transcription, for segments whose language is `el`, each `?` that directly follows a Greek letter becomes `;` (Greek question mark). Raw engine output is kept in `stt_run.raw`; `text` and segments hold the postfixed text.
5. **Step + persistence:** step `stt_transcribe` (`@steps.register`, in `runner/steps_stt.py`): `POST /api/recordings/{id}/stt-runs` validates the model id exists (unknown = 422) and is `kind=stt` (else 422) and `installed` (else 409), inserts a `stt_run` row `queued`, calls `JobService.enqueue("stt", recording_id, steps=[{"name":"stt_transcribe","params":{stt_run_id,...}}])`, returns `202 {stt_run_id, job_id}`. On finish the step inserts all segments + `text` + `wall_ms/audio_ms/rtf` and sets `done` in one transaction (pages never see half a run). A `@steps.on_terminal("stt_transcribe")` finalizer sets the row `failed`/`cancelled` + `error` whenever the job ends that way, including a job cancelled while still queued (so no row stays `queued` forever). The checkpoint in `step_dir` is kept for retry (retry = same job resumes; "Run again" = new row).
6. **API:** `GET /api/recordings/{id}/stt-runs` (list, newest first, with model label, status, wall_ms, rtf), `GET /api/stt-runs/{id}`, `GET /api/stt-runs/{id}/segments`, `DELETE /api/stt-runs/{id}` (409 if `queued` or `running`).
7. **Page `web/analyse/`:** `/analyse?rec=<id>` served from `web/analyse/index.html` (no `rec` = "Pick a recording in Library" linking `/library`). Sections: recording header + native `<audio controls>`; **New run** card (STT model `<select>` filled from `/api/models?kind=stt`, language Ελληνικά/Auto, "tech vocab hint" checkbox, Start disabled with a reason line when the model is unavailable); **progress view** (SSE with polling fallback, stage text, percent, elapsed, Cancel with confirm, "you can close this page"); **Runs list** (`#id · model label · wall time · RTF×`, status text + icon, newest first); **transcript view** (`[mm:ss] text` rows, clicking a row sets `audio.currentTime = start_ms/1000` and plays). Reuses v1 tokens/`shared.css`/nav from foundation. Vanilla JS, no library.
8. **v1 transcript + library count:** a service function `adopt_v1_transcripts()` (idempotent, run in the startup hooks and lazily when a recording's runs list is requested, which covers the offline v1 import CLI) turns each recording's importer-written `v1-transcript.txt` into one `stt_run` (`engine='mlx_whisper'`, `model_id='unknown (v1 import)'`, `status='done'`, `text` from the file, no segments). The library list query gains `runs_count` = `COUNT(stt_run)` per recording.
9. **Out of scope:** one-click STT+AI in a single run (deferred to v2.1, see DESIGN); AI model dropdown/outputs (llm-outputs), compare ticks (compare-runs), diarization, Parakeet/OpenCouncil/sam8000 adapters (v2.1), word-level timestamps (column exists, nullable, not requested).

## Verification
- Failing tests first (fakes from `tests/fakes/engines.py`, async pool + `clean_db`; default suite needs no GPU/model): migration creates both tables + cascade delete; Greek postfix table (`Τι κάνεις?`→`Τι κάνεις;`, `Is it ok?` unchanged, `Gemma?` unchanged); worker with a `fake` engine writes jsonl, is killed mid-run, resumes and does not redo finished windows; `POST` with unknown or `kind=llm` model → 422, not installed → 409; worker prints a heartbeat line at load and per window (asserted on captured stdout); step calls `release_for_stt` before spawn; `on_terminal` marks a run cancelled when its job is cancelled while queued and failed on failure; DELETE of a queued run → 409; adoption of `v1-transcript.txt` creates one done run with no segments and is idempotent; library list returns `runs_count`; failed step leaves no segments; runs list returns label/wall/rtf; page served at `/analyse` and contains the expected element ids.
- Negative case: killing the worker mid-run leaves `stt_run.status='failed'` with zero `transcript_segment` rows and an intact `segments.jsonl`.
- One `@pytest.mark.gpu` smoke test (excluded by default) runs real mlx-whisper turbo on a ~10 s Greek fixture generated with macOS `say -v Melina` (no 77 s fixture exists in the repo).
- Manual: screenshot of `/analyse?rec=<id>` with a finished run, plus a click-to-seek check read from the player's `currentTime`.

## Caveats
- Windowed transcription with `condition_on_previous_text=False` can cut a word at a window edge and loses cross-window context. Default 30 s is the design's choice; edge-word loss is unmeasured (estimate, not measured). Compare against a whole-file run on one recording before trusting window WER.
- "Greek `?`→`;`" rule is a heuristic: a `?` after a Latin word in a Greek sentence stays `?`.
- Language `auto` costs one detect pass; Whisper may mislabel code-switched speech, hence `el` is the default for Greek meetings.
- RTF is wall time on this Mac including cold model load; label it as such, other apps change it.
- The Analyse page shell leaves a visible empty slot for AI model/outputs; llm-outputs fills it. One-click STT+AI in a single run is deferred to v2.1.
